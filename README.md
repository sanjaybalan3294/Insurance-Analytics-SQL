# Insurance Analytics – SQL Project

## 📊 Project Overview

This project analyzes insurance data using SQL to generate business
insights related to customers, policies, premiums, claims, and payments.

## 🛠️ Tools Used

- MySQL
- SQL

## 🔍 Analysis Performed

The project includes SQL queries to analyze:

- Total number of policies
- Total number of customers
- Policy distribution by age group
- Policy distribution by gender
- Policy distribution by policy type
- Policies expiring in 2026
- Premium analysis by year
- Claims analysis by status
- Payment analysis by status
- Total claim amount

## 📈 Key Insights

The analysis helps identify patterns in:

- Customer demographics
- Policy types
- Policy expiration
- Premium collection
- Claim amounts
- Claim status
- Payment status

## 📁 Project Files

- `Insurance_Analytics_.sql` – SQL queries used for the insurance data analysis.
